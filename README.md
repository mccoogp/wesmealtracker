# The Wesleyan Calculator

A simple meal plan tracker for Wesleyan students. Enter your semester dates and current meal point and swipe balances to see how much you can spend each day. Optional fall and Thanksgiving break toggles adjust the day counts.

Live site: https://wesmealtracker.vercel.app

## Built with

- Next.js and React
- Vercel (hosting and Analytics)

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
